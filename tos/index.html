Terms of Service & Privacy

Simple, honest, and friendly. Here’s what the bot stores, why, and how to get your data deleted.

🔒 A note from the bot owner

The bot stores Discord user IDs and per-user records (rank, points, coins, rental tokens, warnings, trust locations, session history) in a local data file (data/bot-data.json). It does not read or store message contents, and it never shares data with third parties.

📁 Data collected

  • Discord user ID — used to associate records with your account. No username, email, or IP address is stored.
  • Server records you accumulate while using the bot — rank, in-game user, reward points, Discord coins, rental tokens, warnings, trusted locations, session history, and Wall of Fame status.
  • Custom commands content is created by staff, not collected from members.

⚙️ How data is used

Your data is used only to run the bot’s features: verification, ranks, the shop, rentals, rewards, and moderation. It is not used for advertising, profiling, or anything else.

👀 Who can see it

Staff members with a staff role (or Manage Server permission) can view and manage bot records as part of running the server. Nobody else has access.

🗑️ Deleting your data

You can ask any staff member to run /unverify @you to remove all of your records from the bot. Once removed, they are gone.

💬 Contact

If you have any questions about this policy, reach out to MIHU staff in the Discord server — we’re happy to explain.

🌸 Questions about the bot itself? See the About page or the Commands.
