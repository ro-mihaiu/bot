About the Bot

MIHULISH is the Discord companion for the MIHU player-warp server — it keeps ranks in order, rewards active players, and helps staff run the warps.

🌸 What is MIHU?

MIHU is a network of player-warps — player-run worlds on Minecraft. Each warp is a different experience:

  • mihu-farm — crops, farming, and woodcutting exp.
  • mihu-rentals — gear and items you can rent for a subscription.
  • mihu-shop — a community shop with stock and restocks tracked by the bot.
  • mihu-casino — mini-games, events, and giveaways.
  • mihu-money — the money island for earning and managing currency.
  • dungeon — dungeon gear, runs, and boss fights.

The bot helps staff run these warps — and rewards the players who keep them alive.

🤖 What does the bot do?

  • Verifies members and manages ranks, from Celestial down to Wanderer.
  • Tracks warnings and moderation actions with unique IDs.
  • Rewards players with points (tradable to Spirit / Blossomcraft) for building, repairing, or donating.
  • Runs a shop inventory and restock tracking for mihu-shop.
  • Manages rental tokens and timed rental sessions for mihu-rentals.
  • Fun currency — Discord coins with a coin-flip game.
  • Runs giveaways with reactions, winners, and rerolls.
  • Lets staff create custom tag commands like .website.

👥 Who can use it?

Any member of the Discord server can use the bot. Some commands are staff-only and are marked with a Staff badge in the command reference.

🆘 How to get help

There are two quick ways to get help with the bot:

  • Run .help in the server to see the prefix-command help text.
  • Contact MIHU staff in the Discord server.
